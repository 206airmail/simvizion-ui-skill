# Dialogs, popovers, tooltips, context menus

Modal: integrated `#0D1B1F` dialog surface with 1px `#294147` border, 8px radius, 12px default padding and standard floating shadow. Distinct elevated header/footer bars only when persistent controls or scroll boundaries justify them. Size to content within functional viewport bounds (320–720px as a starting range, not a mandated width), with scrollable body when necessary; header/footer fixed if middle scrolls. Center horizontally, center vertically offset upward ~32px, clamp to viewport. Backdrop black 50% (no blur), 150ms opacity animation. Dialog title 16px/600, content near-white/secondary. Cancel to left, primary to right, 6px gap; optional footer divider. True modal traps focus, restores trigger after close. Initial focus first relevant control, destructive confirmation focus Cancel. Escape follows Cancel unless focused input's draft Escape handles first. Don't discard substantial unsaved changes on backdrop. Destructive confirmations ignore outside click, never Enter-to-delete implicitly, use explicit focused action.

Popover: elevated surface, 6px radius, 1px border, shadow; 12px padding; max width 360px, max height 70% viewport, scroll content while retaining applicable header/footer. Opens via click/keyboard (not hover), 6px anchor gap, 100ms opacity fade. Outside click/Escape dismiss if no pending protected edits. Header 14px/600, right 28px close icon, footer actions right.

Context menu: elevated surface, 6px radius, 6px internal padding, row 28px high, 8px horizontal padding, 2px between rows, 13px labels, 14px icons with 8px gap. Menu width content-sized up to 320px. Active hovered item bg `#1B3237`; disabled muted and inert. Divider 1px inset 8px, 4px gap either side. Submenus after ~150ms hover or immediate click, 4px horizontal gap, flip at edges and protect pointer path. Destructive commands red icon/text, hover remains neutral. Shortcuts muted on right; check/radio state indicator on right. Keyboard arrows/Enter/Escape supported; Tab closes. 75ms fade.

Tooltip: hover after 300ms, 150ms mouse-leave grace; keyboard focus prompt. Elevated background, 4px radius, 1px border, 10px horizontal/6px vertical padding, 12px font, max width 280px, 6px offset from anchor, 100ms opacity transition, no arrow. Above preferred, flip as needed. Action label near-white, optional shortcut right in muted `#91A6AB` separated by minimum 12px. Nonselectable and noninteractive. No shortcut = show label alone.
